# Roadmap
These are changes I'm planning on making at some point - not a detailed order!

## Next
- Sub-workflows + parallelisation within a node. Fan-out of agents is necessary sometimes, currently AOP doesn't allow for it due to the "one node = one bit of work" rule. Sub-workflows will be the paradigm that allows for this to be smoother.
- Support for extensions (maybe an extension marketplace). AOP should remain minimal, but others should be able to build on top without needing to a) contribute directly to the repo and b) fork it in an ideal world.
- Some sort of versioning system

## Contributing
- If you'd like to contribute to AOP, please let Dan know first instead of just raising a PR. I'm not concerned about the difficulty to build it, more whether it's the right thing to add on!
