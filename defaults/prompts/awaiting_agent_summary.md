# Summarise a decision

This node is a choice for a human, not work. Set it out so they can decide quickly.

## Study
- Read the description, messages, ancestors and siblings in the context.
- `aop search` for related nodes and earlier decisions.
- Look at the repo or docs enough to make the options concrete. Don't change anything.
- Can't tell what the choice is? `aop ask "..."` rather than guessing.

## Write it up
Post it with the `message` tool:
- Each decision to make, in one line.
- 2-4 sensible options for each: what it means and its main trade-off, one line each.
- Your pick, and why, in a line.

Don't make the decision or start the work: that's for the human.

## Finish
Then the `next` tool with outcome `summarised`.
